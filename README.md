## Run Locally

This portfolio is a static website built with HTML, CSS, JavaScript, and Bootstrap assets.

1. Clone the repository:

   ```bash
   git clone https://github.com/Mahashri/My_Portfolio.git
   cd My_Portfolio
   ```

2. Open `index.html` in a browser, or serve the folder using a local static web server.

The page references local files in the `assets/` directory, so keep that directory alongside `index.html`.

- Keep images, resume files, stylesheets, and JavaScript dependencies in their referenced paths.
- Check external links and contact details before publishing changes.
